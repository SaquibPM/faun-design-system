# Changelog

Per-package changelogs (`packages/*/CHANGELOG.md`) are generated by [Changesets](https://github.com/changesets/changesets) from the next release onward. This file records the initial release.

## 0.1.0

First public release of all packages at `0.1.0`: `@faun-ds/tokens`, `@faun-ds/icons`, `@faun-ds/grid`, `@faun-ds/react`, `@faun-ds/data`, `@faun-ds/ai`, `@faun-ds/eslint-plugin` and `@faun-ds/mcp`.

- **Tokens:** 12-step colour scales, semantic roles and interaction states, five themes (`light`, `dark`, `light-hc`, `dark-hc`, `print`) plus `system`, three densities, type, space, shape, elevation, motion and layout tokens as CSS variables, typed JS, JSON and a Tailwind v4 preset (standard and strict). `createAccent()` generates a validated tenant accent. A contrast contract is checked on every build. IBM Plex fonts through Fontsource (`fonts.css`, optional peer dependencies) or Google Fonts.
- **Icons:** 173 accessible, tree-shakeable React icons (a curated Lucide set plus ESG and agent glyphs), an SVG sprite and a manifest.
- **React:** 60+ accessible components on Radix primitives with plain CSS in cascade layers, including the app shell, forms, overlays, navigation, feedback and display components. `"use client"` directives for the Next.js App Router.
- **Data:** `DataTable`, `FilterBar`, `JsonViewer`, `DataQualityCell` and 20+ charts, each with a hidden data table, keyboard navigation and a colour-vision-safe palette.
- **AI:** run trails, approval gates, provenance, citations, confidence, streaming text, prompt composer, chat and artifact panels.
- **Grid:** 12-column responsive grid (4, 8 and 12 columns) as CSS and React `Grid` and `Column`.
- **ESLint plugin:** rules for raw colours, arbitrary Tailwind values, unlabelled icon buttons and status shown by hue.
- **MCP server:** `faun-mcp` gives coding agents components, props, tokens, the status map and icons.
