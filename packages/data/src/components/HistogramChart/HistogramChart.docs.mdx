## When to use

- To see the spread of one measure across many items: supplier intensity, invoice lead times, meter readings.
- To check a limit against the whole population with a reference line.

## When not to use

- To compare categories. Use a bar chart.
- To compare distributions across groups. Use a box plot.
- For fewer than about twenty values. Show the values themselves.

## Anatomy

Title and description, the plot (grid, count axis, measure axis with its title, contiguous bars, reference lines) and a tooltip with the range and the count. Bars touch because the ranges are continuous.

## Colour

One categorical colour (`dataviz.cat-1` unless you set `color`). A histogram shows one measure, so it needs no legend.

## Notes

- Pass the raw `values`. The chart counts them. Set `binWidth` (in the unit of the values) or `bins`; by default the count follows Sturges' rule between 4 and 20.
- Bins are half open: a value on a boundary goes in the upper bin, and the maximum goes in the last bin.
- `references` takes `{ label, value, kind }`. Use `kind: "target"` for a goal and the default for a baseline or limit. Keep to one or two lines so labels stay clear of each other. References are vertical lines on the measure axis.
- `binValues(values, bins, binWidth)` is exported for building tables or tests from the same counts.
- The width follows the container; set `height` in px to change the plot height.
- No chart library is used. The chart is plain SVG, so it prints and themes with the tokens. Colours are always data-viz tokens; a test fails if any chart source contains a literal colour.

## Screen readers

- The chart is a figure named by its title. The drawing is hidden from assistive technology; a data table with every value, its unit and “No data” gaps takes its place.
- Moving with the arrow keys announces the range and its count in a polite live region.
- The data table lists each range and its count, and any reference lines at the foot.

## Visual

- Hovering shows a tooltip with the values for the mark under the pointer; keyboard focus shows the same tooltip.
- Marks against the surface meet 3:1 in every theme, and the categorical palette is checked for protan and deutan separation.
- Bin edges are labelled on the axis, not inside the bars, so narrow bars stay legible.
