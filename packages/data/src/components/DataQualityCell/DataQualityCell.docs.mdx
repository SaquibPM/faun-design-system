## When to use

- In a table column or detail row where a disclosed figure may be estimated, partial or missing.
- Anywhere a number goes into a report and a reviewer needs to see its provenance.

## When not to use

- For workflow state such as draft or approved. Use StatusBadge with the lifecycle or approval domain.
- For a figure that is always an actual. Show the number alone.

## Writing

Source lines are short and specific: “Utility invoices, Jan to Dec 2025”, “Spend-based, EEIO factors”. Do not repeat the state in the source.

## Notes

- The tone, icon and label come from `@faun-ds/tokens/status-map` (`data-quality`). Products extend the map; they do not add tones here.
- Omit `value` for `missing` and `gap`. The cell shows a dash and speaks “No value”.
- A real `"0"` is a value and stays visible.

</Section>

<Section tab="accessibility">

## Keyboard

The cell is not interactive.

## Screen readers

- The badge carries the quality as text (“Estimated”), read after the figure. The icon is decorative.
- A missing value is announced as “No value”, then the state.

## Visual

- State is icon plus label plus tone, never colour alone. Tones meet 4.5:1 on their backgrounds.
