## When to use

- To compare a measure across a small set of categories: sites, suppliers, frameworks, years.
- To show the same measure two ways side by side, such as location-based and market-based Scope 2.

## When not to use

- For change over time with many points. Use a line chart.
- For parts of a whole with many parts. Use a treemap, or a donut for a few.
- For exact values people need to look up. Use a data table, or add `showValues`.
- For more than about a dozen categories. Group the tail as “Other”, or use a table.

## Writing

Title the chart with what it shows and the period: “Scope 1 emissions by site, FY2026”. Use the description for the one-line takeaway. Put the unit in `unit`, not in every label.

## Anatomy

Title and description, an optional legend, the plot (grid, value axis with unit, category axis, bars), and a tooltip. Gridlines are quiet, bars have a hairline surface edge so neighbours stay distinct.

## Colour

Series take `dataviz.cat-1` to `cat-8` in order, and never cycle: a ninth series is not drawn. Eight is the limit of what the palette separates for colour-blind readers; group the rest. Series with the id `scope-1`, `scope-2` or `scope-3` take the GHG scope colours. The diverging variant colours by sign instead, from `dataviz.div-neg-3` through `div-mid` to `div-pos-3`: moss is the better side and oxblood the worse (set `positiveIs`). `dataviz.div-alt-*` is the same ramp in blue and amber, for audiences where green and red cannot be told apart.

## Appearance

Charts draw in relief by default: a tinted face with a wave texture, a thin outline and a darker extruded side, with a distinct wave per series. Set `appearance="flat"` for the classic solid look, or `data-appearance="flat"` on any ancestor to flatten charts and buttons beneath it. High-contrast themes, print and forced colours draw flat solid fills with a hatch automatically.

<Example of="BarChart/Appearance" layout="stretch" code="open" />

## Pastel palettes

Four colour options, one prop. `palette="default"` is Faun's saturated categorical set. `meadow`, `dawn` and `harbour` are pastel: the face of each bar is a soft tint, and the outline, side and wave texture, derived from a deeper colour of the same hue, carry the 3:1 contrast. Moss stays series 1 in all of them. Set `data-viz-palette` on any ancestor to recolour every chart beneath it. Lines, points and flat bars use the deep colour, and high-contrast themes and print always use the default palette.

## Notes

- `palette` is `default`, `meadow`, `dawn` or `harbour`. The same switch is `data-viz-palette` on any ancestor.
- `appearance` is `relief` (default) or `flat`. Texture is a second channel besides colour; it never replaces the tooltip or data table.
- `categories` and each series' `values` line up by index. Use `null` for no data.
- `variant` is `simple` (default), `grouped`, `stacked`, `floating`, `diverging` or `lollipop`. Stacked bars put positive values above the baseline and negative values below it. Floating series need `base`, the lower end of each bar.
- `orientation="horizontal"` swaps the axes. Long category names are truncated at 32 characters in the drawing; the data table has the full name.
- `references` takes `{ label, value, kind }`. Use `kind: "target"` for a goal and the default for a baseline or limit. Keep to one or two lines so labels stay clear of each other.
- `toggleSeries` makes the legend interactive. Control it with `hiddenSeries` and `onHiddenSeriesChange` (ids of the hidden series), or start from `defaultHiddenSeries`. Colours stay with their series when others are hidden.
- The width follows the container; set `height` in px (default 280).
- `format` controls ticks, tooltip and table; the default adds thousands separators and up to one decimal.
- No chart library is used. The chart is plain SVG, so it prints and themes with the tokens.

## Screen readers

- The chart is a figure named by its title. The drawing is hidden from assistive technology; a data table with every value, unit and “No data” gaps takes its place.
- Moving with the arrow keys announces the category and all its values in a polite live region.

- With `toggleSeries`, each legend entry is a button with `aria-pressed` (true = shown). Hiding or showing is announced politely, for example “Market-based hidden”. The last visible series is marked `aria-disabled` and stays on.
- Hidden series leave the drawing, the tooltip, the live announcements and the data table, so what is read matches what is seen.
- Target and reference lines are listed at the foot of the data table with their kind, label and value, for example “Target: 2030 pathway: 14,000 tCO₂e”.

## Visual

- Hovering a category highlights it and shows a tooltip with every series. The same appears on keyboard focus.
- Series are told apart by position and legend order as well as colour. The categorical palette is checked for protan and deutan separation.
- Bar fills against the surface meet 3:1.
- Diverging bars are told apart by direction (left or right of the baseline, above or below) as well as colour, and the colour key names both sides.
