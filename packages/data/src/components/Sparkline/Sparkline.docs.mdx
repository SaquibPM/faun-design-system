## When to use

- Beside a figure or in a table cell to show direction at a glance.
- On a dashboard row where every KPI needs a trend.

## When not to use

- When readers need values or axes. Use a line chart.
- As the only place a number appears. Show the figure too.
- For comparing trends with different scales. Each sparkline scales to its own data.

## Writing

The title is read by screen readers and used for the data table, so write it as a full phrase: “Scope 2 emissions by month, tCO₂e”. Give `labels` so the tooltip names each point.

<Section tab="style">

## Anatomy

A single plot with no axes, grid, legend or visible title: a line with an end dot, a filled area, or small bars. A tooltip appears on hover and focus.

## Colour

One categorical colour (`dataviz.cat-1` unless you set `color`). The area is the same colour at low opacity.

## Notes

- `width` (default 120) and `height` (default 32) are in px; the sparkline is an inline block.
- The line scales to the range of its data; bars and areas start at zero.
- `showEnd` marks the last value with a dot.
- Sparklines have no legend or series toggle.
- The width follows the container; set `height` in px to change the plot height.
- No chart library is used. The chart is plain SVG, so it prints and themes with the tokens. Colours are always data-viz tokens; a test fails if any chart source contains a literal colour.

## Screen readers

- The chart is a figure named by its title. The drawing is hidden from assistive technology; a data table with every value, its unit and “No data” gaps takes its place.
- Moving with the arrow keys announces the point's label and value in a polite live region.
- Every sparkline has a hidden data table with each point's label and value.

## Visual

- Hovering shows a tooltip with the values for the mark under the pointer; keyboard focus shows the same tooltip.
- Marks against the surface meet 3:1 in every theme, and the categorical palette is checked for protan and deutan separation.
- Because the plot is small, the active point gets a ring so it can be seen under a finger or a cursor.
