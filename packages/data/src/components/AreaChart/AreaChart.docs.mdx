## When to use

- To show a total or a volume over an ordered axis: monthly consumption, cumulative savings.
- Stacked, to show how the parts of a total change over time: supply by source, emissions by scope by month.

## When not to use

- To compare exact values across a few categories. Use a bar chart.
- For many overlapping series. Simple areas hide each other; stack them, or use a line chart.
- For values that do not start at zero. The fill implies the baseline.

## Writing

Title the chart with what it shows and the period: “Electricity supply by source, 2026”. Use the description for the one-line takeaway. Put the unit in `unit`.

## Anatomy

Title and description, an optional legend, the plot (grid, value axis with unit, category axis, a translucent fill and a solid line per series) and a tooltip. A guide line and a marker follow the active category.

## Colour

Series take `dataviz.cat-1` to `cat-8` in order, and never cycle. Series with the id `scope-1`, `scope-2` or `scope-3` take the GHG scope colours. The fill is the series colour at low opacity, so gridlines stay visible through it.

## Notes

- `variant` is `simple` (default) or `stacked`. Stacked areas treat a missing or negative value as zero.
- `categories` and each series' `values` line up by index. Use `null` for no data.
- `references` takes `{ label, value, kind }`. Use `kind: "target"` for a goal and the default for a baseline or limit. Keep to one or two lines so labels stay clear of each other.
- `toggleSeries` makes the legend interactive. Control it with `hiddenSeries` and `onHiddenSeriesChange` (ids of the hidden series), or start from `defaultHiddenSeries`.
- The width follows the container; set `height` in px to change the plot height.
- No chart library is used. The chart is plain SVG, so it prints and themes with the tokens. Colours are always data-viz tokens; a test fails if any chart source contains a literal colour.

## Screen readers

- The chart is a figure named by its title. The drawing is hidden from assistive technology; a data table with every value, its unit and “No data” gaps takes its place.
- Moving with the arrow keys announces the category and all its values (and the total, when stacked) in a polite live region.
- With `toggleSeries`, each legend entry is a button with `aria-pressed`. Hidden series leave the drawing, tooltip, announcements and data table.
- Target and reference lines are listed at the foot of the data table.

## Visual

- Hovering shows a tooltip with the values for the mark under the pointer; keyboard focus shows the same tooltip.
- Marks against the surface meet 3:1 in every theme, and the categorical palette is checked for protan and deutan separation.
- The fill is never the only cue: each series also has a line and, on hover, a marker shape of its own.
