## When to use

- To inspect agent run inputs and outputs, tool calls, evidence records and API payloads.
- When people need to explore structure and copy the exact text.

## When not to use

- For values people should read as a form. Use a description list.
- For code samples. Use a code block.
- For tabular records. Use a data table.

## Anatomy

A toolbar (Expand all, Collapse all, Copy), then the tree. Keys are medium weight, punctuation is muted, and values are coloured by type: strings (success), numbers (info), booleans (attention), null (muted, italic). Types also read from syntax: strings are quoted.

## Notes

- Pass any JSON-serialisable value to `data`. Copy writes `JSON.stringify(data, null, 2)`; `onCopied` receives the text.
- Collapse all keeps the first level open; use `defaultExpandedDepth={0}` for a fully closed start.
- The viewer is read-only.

## Screen readers

- The viewer is a group with the label you give it. Each toggle is a button with `aria-expanded`, named with the key and its size, for example “output, 2 keys”.
- Copying is confirmed in a polite status: “Copied JSON to clipboard”, and the button's name changes to “Copied”.
- The scroll area is focusable so keyboard users can scroll long payloads.

## Visual

- Value types are not told by colour alone. Value colours meet 4.5:1 on the nested surface.
