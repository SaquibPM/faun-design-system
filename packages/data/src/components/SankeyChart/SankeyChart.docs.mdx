## When to use

- To follow a quantity through stages: energy source to scope to site, spend by category to region.
- To show where the largest flows go, and what feeds each destination.

## When not to use

- For more than about fifteen nodes or thirty flows. It turns to spaghetti.
- For exact comparison. Use a stacked bar chart.
- For flows that loop back. Sankey diagrams read left to right.

Title with what flows and the period. Node names should be short nouns; they sit beside the nodes.

## Anatomy

Title and description, the plot (node bars in columns, ribbons between them whose width is the flow, node labels at the edges) and a tooltip for the flow or node under the pointer.

## Colour

Nodes in the first column take `dataviz.cat-1` to `cat-8` in order; later nodes take the colour of the source that feeds them most. A node with the id `scope-1`, `scope-2` or `scope-3` takes the GHG scope colour. Ribbons are the source colour at low opacity.

## Notes

- `nodes` are `{ id, label, color? }` and `links` are `{ source, target, value }`. Links with a zero value, an unknown node or the same source and target are ignored.
- A cycle does not stop the chart drawing; the layout cuts it at a bounded number of passes.
- The chart is called an alluvial diagram in some libraries; this is the same component.
- `sankeyLayout(nodes, links, width, height)` is exported for tests and custom drawings.
- The width follows the container; set `height` in px to change the plot height.
- No chart library is used. The chart is plain SVG, so it prints and themes with the tokens. Colours are always data-viz tokens; a test fails if any chart source contains a literal colour.

## Screen readers

- The chart is a figure named by its title. The drawing is hidden from assistive technology; a data table with every value, its unit and “No data” gaps takes its place.
- Moving with the arrow keys announces the flow's source, target, value and share of its source, or the node's total, inflow and outflow in a polite live region.
- Flows are read first, then nodes. The data table lists every flow, and node totals at the foot.

## Visual

- Hovering shows a tooltip with the values for the mark under the pointer; keyboard focus shows the same tooltip.
- Marks against the surface meet 3:1 in every theme, and the categorical palette is checked for protan and deutan separation.
- Pointing at a ribbon or a node selects it; the ribbon is highlighted.
