## When to use

- Standard: usage against a limit or capacity: carbon budget used, storage used.
- Proportional: the parts of one whole in a row: Scope 3 by category, spend by region.

## When not to use

- For a value without a maximum. Use a Stat.
- For several measures. Use a bullet chart.
- For a task's progress. Use the Progress component.

## Anatomy

Title, a value line above the bar (value and status in text), the bar (track, fill, thin zone strip beneath) and min and max labels. Proportional: segments in order with hairline gaps and a legend.

## Colour

Standard uses `dataviz.cat-1` unless `zones` apply, in which case the bar takes the status colour of the zone the value is in. The status is always written next to the value. Proportional segments take `dataviz.cat-1` to `cat-8` in order.

## Notes

- Standard: `value`, `max` (default 100) and optional `zones` of `{ from, tone, label }`, ascending.
- Proportional: `segments` of `{ id, label, value }` and `max` as the whole; any remainder shows as the empty track.
- Proportional meters support `toggleSeries`; standard meters have no legend.
- The width follows the container; set `height` in px to change the plot height.
- No chart library is used. The chart is plain SVG, so it prints and themes with the tokens. Colours are always data-viz tokens; a test fails if any chart source contains a literal colour.

## Screen readers

- The chart is a figure named by its title. The drawing is hidden from assistive technology; a data table with every value, its unit and “No data” gaps takes its place.
- Moving with the arrow keys announces the value against the maximum and the status (standard), or the segment, its value and share of the whole (proportional) in a polite live region.
- The data table lists the value, maximum, share and status (standard), or each segment with its share of the whole.

## Visual

- Hovering shows a tooltip with the values for the mark under the pointer; keyboard focus shows the same tooltip.
- Marks against the surface meet 3:1 in every theme, and the categorical palette is checked for protan and deutan separation.
- Status zones are also drawn as a thin strip beneath the bar, so where the thresholds lie is visible.
