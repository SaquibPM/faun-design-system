## When to use

- To find patterns across two dimensions: emissions by site and month, risk by supplier and topic.
- Diverging: variance, change or deviation from a target around a neutral midpoint.

## When not to use

- For a few values. Use a bar chart.
- When readers need exact values. Add `showValues`, or use a data table.
- For a continuous map. Heatmaps are grids.

## Writing

Title with the measure and both dimensions. Keep row and column names short; long names are truncated in the drawing and complete in the table.

<Section tab="style">

## Anatomy

Title and description, a colour key (a ramp with the values at each end, and the midpoint for diverging), the plot (column labels on top, row labels at the left, cells with hairline gaps, optional values in cells) and a tooltip.

## Colour

Sequential: `dataviz.seq-1` to `seq-7` (the moss ramp), light to dark, in seven steps; `dataviz.seq-neutral-1` to `seq-neutral-7` is the warm-grey ramp. Diverging: `dataviz.div-neg-3` through `div-mid` to `div-pos-3`; negative is oxblood and positive is moss by default, so with `positiveIs="worse"` the oxblood end marks values above the midpoint. Missing data is a dashed empty cell, not a colour.

## Notes

- `values` is an array per row with one entry per column. Use `null` for no data.
- `domain` fixes the ends of the scale (useful to compare two heatmaps); `midpoint` sets the neutral value of a diverging scale.
- Cell values are written only when `showValues` is on and cells are large enough, with a surface halo so the text reads on any shade.
- The width follows the container; set `height` in px to change the plot height.
- No chart library is used. The chart is plain SVG, so it prints and themes with the tokens. Colours are always data-viz tokens; a test fails if any chart source contains a literal colour.

## Screen readers

- The chart is a figure named by its title. The drawing is hidden from assistive technology; a data table with every value, its unit and “No data” gaps takes its place.
- Moving with the arrow keys announces the row, column and value in a polite live region.
- The data table is a matrix with the row names down the side and the column names across.

## Visual

- Hovering shows a tooltip with the values for the mark under the pointer; keyboard focus shows the same tooltip.
- The sequential and diverging ramps are ordered by lightness, so shade can be read without hue.
- A colour key states the value at each end of the scale.
