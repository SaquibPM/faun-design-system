## When to use

- To compare a profile across five to eight measures that share one scale: maturity by disclosure area, supplier scores by criterion.
- To lay one or two subjects against a target profile.

## When not to use

- For measures in different units. Use small multiples of bar charts.
- For exact comparison. Use a bar chart; areas on a radar are hard to read.
- For fewer than three measures, or more than about eight.

## Writing

Title with the subject and period. Name each axis with a short noun phrase; long names are truncated in the drawing but kept in the data table.

## Anatomy

Title and description, a legend, the plot (concentric rings with value labels, one spoke and label per category, one polygon per series with markers) and a tooltip listing every series on the active axis.

## Colour

Series take `dataviz.cat-1` to `cat-8` in order. Each series has a translucent fill, a solid outline and its own marker shape, so overlapping polygons stay distinguishable. Target rings use the quiet reference styling shared with the other charts.

## Notes

- `categories` are the axes; each series' `values` line up with them. A `null` value is skipped and read as “No data”.
- `max` sets the value at the outer ring. By default it is the largest value or reference, rounded up.
- `references` takes `{ label, value, kind }`. Use `kind: "target"` for a goal and the default for a baseline or limit. Keep to one or two lines so labels stay clear of each other.
- `toggleSeries` makes the legend interactive. Control it with `hiddenSeries` and `onHiddenSeriesChange` (ids of the hidden series), or start from `defaultHiddenSeries`.
- The width follows the container; set `height` in px to change the plot height.
- No chart library is used. The chart is plain SVG, so it prints and themes with the tokens. Colours are always data-viz tokens; a test fails if any chart source contains a literal colour.

## Screen readers

- The chart is a figure named by its title. The drawing is hidden from assistive technology; a data table with every value, its unit and “No data” gaps takes its place.
- Moving with the arrow keys announces the axis name and each series' value on it in a polite live region.
- The data table has one row per axis and one column per series.

## Visual

- Hovering shows a tooltip with the values for the mark under the pointer; keyboard focus shows the same tooltip.
- Marks against the surface meet 3:1 in every theme, and the categorical palette is checked for protan and deutan separation.
- Pointing anywhere selects the axis nearest the pointer's angle.
