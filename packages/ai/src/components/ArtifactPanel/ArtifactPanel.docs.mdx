## When to use

- When an agent produces something a person will read, check or reuse: a disclosure draft, a table of figures, a chart, a block of code.
- When the person should keep the conversation in view while they read it, so they can ask for a change.

## When not to use

- For a short answer. Keep it in the message.
- For a long task that needs review and sign-off on its own page. Use a page template, and link to it from the message.
- For a modal choice. Use [Dialog](/components/dialog).

## Writing

- The title is the thing: “ESRS E1-6 draft”, not “Result”. The kind above it is one word: Document, Table, Chart, Code.
- Label versions with a number and a time: “v3, 10:42”. Newest first.
- The message that opens the panel says what changed in it, so the panel does not have to.

## Anatomy

A header with the kind, the title, a version picker, Copy, Download, Maximise and Close. Under it a Preview and Code tab list and the active pane, which scrolls on its own. A resize handle sits on the leading edge. Docked beside a thread the panel has a hairline border and no shadow; as a sheet it is raised.

## Sizes

Default width 560 px, minimum 320 px, maximum 960 px or whatever leaves 360 px for the thread. Under 768 px of layout width it fills the screen and the thread is inert. Maximise is hidden there because it is already maximal.

## Notes

- `onClose` is required. Return focus to the control that opened the panel in it; the panel also restores the previously focused element when it unmounts.
- Inside a [Chat layout](/components/chat-layout) the layout owns the width and the maximised state, and tells the panel when it must be a sheet. Standalone, use `width`, `defaultWidth`, `maximized` and their change callbacks.
- Copy and Download use `copyText`, or `code` when it is a string. Download writes a text file named by `filename`. Pass `onDownload` for anything else.
- Pass `code` as a node to show highlighted source from your own renderer. Pass `copyText` as well so Copy still works.
- `versions` and `version` are controlled by your data: when the version changes, rerender `preview` and `code` with that version's content.

## Screen readers

- The panel is a region named by its title, which takes focus when the panel opens.
- The resize handle is a separator with `aria-valuenow`, `aria-valuemin` and `aria-valuemax` in pixels.
- Maximise is a toggle button with `aria-pressed` and a label that changes between “Maximise panel” and “Restore panel size”.
- Copy announces “Copied to the clipboard” or “Copy failed” in a polite live region.
- As a sheet, the thread behind is `inert`: focus and the virtual cursor stay in the panel.

## Visual

- Every action is an icon button with a label and a tooltip. Targets meet the minimum size.
- Focus is visible on the handle, the tabs, the buttons and the scrolling panes.
- Motion is a short fade, removed under reduced motion.
