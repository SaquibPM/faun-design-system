## When to use

- For an assistant a person talks to in the product: asking about a figure, drafting a paragraph, finding a filing.
- Together with [Prompt composer](/components/prompt-composer) to type, and [Streaming text](/components/streaming-text), which a reply uses while it arrives.

## When not to use

- For a run an agent performs on its own. Use [Run trail](/components/run-trail).
- For a single AI value in a form. Use [AI slot](/components/ai-slot).

## Writing

Replies are short, state the answer first and name the figure and its unit. Suggested prompts are the questions people actually ask, under about six words.

## Anatomy

A list of messages. A reply has a header (agent chip, AI label, time), the body, a numbered source list and the feedback row. The person's own message is a tinted bubble aligned to the end, never given the AI treatment, so machine and human text are always distinguishable.

## Notes

- `AIChatMessage` takes `text` (streamed with StreamingText) or `children` for rich content with its own citation markers.
- `state` is `streaming`, `complete` or `stopped`; `onStop` shows the Stop button while streaming.
- `feedback` takes the AIFeedback props (rating, copy, regenerate, reasons) or `false` to leave it out.
- `citations` appear under a completed reply and also feed the AI label's explanation.

## Screen readers

- The list is a log named “Conversation” with live updates off. A streaming reply announces “Generating response” and “Response complete” itself, so people are not read every word.
- Each message is an article named for its speaker and time.

## Visual

- Replies are marked by words (agent name, “AI generated”), not by colour. Message text keeps 7:1 body contrast.
