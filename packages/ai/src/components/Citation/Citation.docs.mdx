## When to use

- After any statement or figure an agent wrote that rests on evidence: a survey answer, an invoice, an emission factor.
- Under generated narrative, as a list of sources a reader can open and check.

## When not to use

- To show how a number was calculated. Use [Provenance trail](/components/provenance-trail).
- For links in ordinary content. Use [Link](/components/link).

## Writing

- Source titles name the thing as people know it: “Supplier survey 2026”, “Invoice INV-20931”.
- Locators are exact: “Sheet 2!C14”, “p. 2”. A reviewer should reach the passage in one step.
- Quote the passage that supports the claim, not the whole document.

<Section tab="style">

## Anatomy

A marker is a 16px pill with the number, in the AI roles so it reads as generated-content metadata. A source card shows the title (a link when there is an address), a line with the kind icon, kind, publisher, locator and retrieval time, and the quoted passage on a rule. A source list is a numbered stack of the same.

## Notes

- A `Citation` pairs a 1-based `index` with a `Source`. Number markers in order of first use.
- `SourceList` gives each entry the id `<idPrefix>-<index>` so your own links can point at it.
- A marker's accessible name is “Source 1: Supplier survey 2026”.

## Screen readers

- Markers are buttons named by number and source title. The card is a dialog with the same name.
- The source list is an ordered list, so its numbers match the markers.

## Visual

- The visible marker is small. Its hit area extends to the minimum target size.
- Marker text meets 4.5:1 on the AI wash in every theme.
