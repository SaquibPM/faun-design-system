## When to use

- Wherever work is attributed: run steps, approvals, drafts, comments, audit rows.
- To keep machine work and human work visibly apart. Machines are lagoon, people are plum.

## When not to use

- For a person's profile or menu. Use [Avatar](/components/avatar).
- For categories or filters. Use [Tag](/components/tag).

## Writing

- Use the agent's product name: “CSRD Filing Orchestrator”, “Scope 3 Sub-agent”. Use a person's full name.
- Roles are short and in sentence case: “Sub-agent · Value chain”, “Sustainability lead”.

<Section tab="style">

## Anatomy

A pill with a mark (a kind icon for machines, an extra-small avatar for people), the name, and optional kind and role in a lighter weight.

## Kinds

Agent, Sub-agent, tool, model and system each have an icon or are neutral. People use their photo or initials. Machines never look like people, and the reverse.

## Tokens

<UsesTokens names={["status.running.fg", "status.running.bg", "status.attention.fg", "status.attention.bg", "status.neutral.fg"]} />

The chip borrows the lagoon and plum hues of the running and attention tones to say machine and human. It names identity, not state, so it does not replace a status badge.

## Screen readers

- The accessible text is the name, then the kind and role: “Scope 3 Sub-agent, Sub-agent, Sub-agent · Value chain”. The mark is decorative.

## Visual

- Kind is shown by an icon and in words, never by colour alone. Text meets 4.5:1 in every theme.
