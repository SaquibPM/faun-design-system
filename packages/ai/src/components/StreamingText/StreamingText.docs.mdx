## When to use

- For a draft, summary or answer that a model produces token by token.
- Anywhere generated text should be marked as a draft and attributed to the agent that wrote it.

## When not to use

- For text that is already complete. Pass `state="complete"` or render plain content.
- For a long job with steps. Use [Run trail](/components/run-trail).

<Section tab="style">

## Anatomy

An attribution line with the sparkle and agent chip, and a “Writing” badge while streaming. The text on a soft AI wash with a quiet caret. A Stop button below, and a note when stopped.

## Motion

New text fades in over 200ms. Nothing moves, scrolls or reflows apart from the text that grows. The caret breathes slowly. With reduced motion the text appears at once and the caret is still.

## Notes

- Pass the whole text received so far in `text`. The component animates only what was added. If the text is replaced rather than extended, it starts over.
- Set `state` to `streaming`, then `complete` or `stopped`. Call your abort in `onStop` and set `stopped`.
- Only the last twelve chunks keep their own element, so long responses stay light.

## Screen readers

- The text is not a live region, so assistive tech is not interrupted by every word. A polite status says “Generating response”, then “Response complete” or “Generation stopped”.
- While streaming the text region is marked busy.

## Visual

- Respects `prefers-reduced-motion`: no fade, no caret animation.
- State is shown in words (“Writing”, “Stopped”), not by colour.
