## When to use

- On any content an agent wrote or filled in that a person has not written themselves: a drafted paragraph, an extracted value, a suggested field.
- Next to the content, never in a footer or a tooltip. The label stays after a person accepts, so the origin is never lost.

## When not to use

- To show who is speaking in a conversation. [Actor chip](/components/actor-chip) does that, and the chat message already includes the label.
- For how sure the agent is on its own. Use [Confidence badge](/components/confidence-badge); the label shows it inside the explanation.
- As decoration on features that are merely AI-assisted behind the scenes.

## Writing

“AI generated” for content as produced, “AI suggested” while it awaits a decision, “AI generated, edited” after a change. The summary is one or two plain sentences about inputs, not about the model.

## Notes

- `agent`, `model`, `summary`, `confidence`, `sources`, `actions` all feed the explanation; omit what you do not have.
- `onRevert` adds the Revert action; `modified` controls whether it is enabled (default enabled).
- It is a popover: `open`, `defaultOpen` and `onOpenChange` control it.

## Screen readers

- A button named by its visible words, or “AI generated. Show details” for the icon kind. It reports expanded state.
- The explanation is a dialog named “About this AI content”; the facts are a description list and the sources a labelled list.

## Visual

- The words carry the meaning, not the colour: the pill is recognisable in forced colours by its border and text. The label meets 4.5:1 on its tint.
