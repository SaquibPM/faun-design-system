## When to use

- Next to an extracted value, a matched supplier or a drafted statement, so people know where to look first.
- In a table of agent output, to sort and filter by what needs a human check.

## When not to use

- For the status of a run or task. Use [Badge](/components/badge) with the status map.
- For data quality of a reported figure (actual, estimated, gap). Use a data-quality status badge.

## Writing

- The level is always a word: High, Medium or Low confidence.
- Reasons name the evidence gap: “Matched on supplier name only. No unit of measure found.”
- Low confidence is a prompt to check, not an error. It uses the warning tone, never danger.

<Section tab="style">

## Anatomy

A badge with a three-bar glyph that fills one, two or three bars, the level in words, and an optional score. Sizes: `md` (default) and `sm` for tables.

## Colour

High is success, medium is neutral and low is warning. The glyph and the word carry the level, so it is readable in grayscale and high contrast.

## Notes

- `confidence` is the shared `Confidence` shape: `level`, optional `score` from 0 to 1, optional `reason`.
- Scores are shown as whole percentages. Round in your own code if you need another style.

## Screen readers

- The level is text. The reason is part of the badge's description, so it is read without opening the tooltip.

## Visual

- Three states differ by glyph fill, word and tone. The tooltip repeats content that is already available to assistive tech.
