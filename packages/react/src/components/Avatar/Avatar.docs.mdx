## When to use

- Next to an actor's name in activity feeds, approvals, comments and ownership fields.
- In groups to show reviewers, owners or participants at a glance.

## When not to use

- As the only identification of someone in a decision or audit trail: always show the name too.
- For organisations, sites or data sources: use an icon.

## Notes

- Images load through Radix Avatar; initials or the agent mark show until the image loads and if it fails.
- Use `decorative` when the name is printed next to the avatar, so screen readers don't hear it twice.

<Section tab="accessibility">

## Keyboard

Avatars are not focusable. Wrap one in a link or button if it opens a profile.

## Screen readers

- By default an avatar is `role="img"` named after the person or agent, plus its status ("Ledger Resolver, working").
- `decorative` removes it from the accessibility tree.
- AvatarGroup is a named group listing every member.

## Visual

- Initials meet 4.5:1 on their tint in every theme. Status rings are 2px and are also announced, so colour is never the only signal.
