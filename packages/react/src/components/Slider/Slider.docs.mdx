## When to use

- To choose a value where roughly right is good enough: a confidence cut-off, a materiality threshold.
- To choose a range between two bounds.

## When not to use

- For exact values such as emissions. Use [Number field](/components/number-field).
- For a small set of options. Use [Segmented control](/components/segmented-control).

## Writing

Label what is chosen and show the unit in the value: “80%”. Keep the range short enough to be useful.

## Warn, read-only and loading

<Example of="Slider/StateContract" title="Warn, read-only and skeleton" description="Warn marks a value that is allowed but worth a second look. It is never the same as invalid: it does not set aria-invalid and never blocks submission, and the message carries an icon and text so it is not colour alone. Read-only shows the value flat, keeps it focusable and copyable, and ignores changes. Skeleton replaces the control while its data loads; the label stays for screen readers. Set all three on a Field and every control inside follows." />

Set `warn` (a message), `readOnly` and `skeleton` on the surrounding `Field`. On a standalone slider, pass `readOnly` and `skeleton` directly; give `warn` a message through a Field so it is announced. An error always replaces a warning.

## Notes

- `value` is always an array: one number, or two for a range.
- `formatValue` formats the displayed value. `thumbLabels` names each thumb of a range.
- `onValueChange` fires while dragging; `onValueCommit` fires on release.

## Screen readers

- Each thumb is announced as a slider with its value, minimum and maximum. Range thumbs are named by `thumbLabels`.

## Visual

- The thumb meets the minimum target size and has a visible focus ring. The value is also shown as text.
