## When to use

- Beside an action to teach its shortcut: in menus, tooltips, the command palette and search field hints.
- In documentation and help text when naming a key.

## When not to use

- To decorate text that isn't a key.
- As the only way to discover a shortcut: shortcuts need visible alternatives.

## Notes

- Symbols map to names for assistive technology: ⌘ Command, ⌥ Option, ⇧ Shift, ⌃ Control, ↵ Enter, arrows, Esc.
- Tooltip and IconButton accept a `shortcut` string and render it with Kbd.

<Section tab="accessibility">

## Keyboard

Kbd is not interactive.

## Screen readers

- Combinations and symbol keys are given an `aria-label` with spoken names; the visual caps are hidden to avoid double reading.

## Visual

- Caps meet 4.5:1 for their text and a visible border in forced-colours mode.
