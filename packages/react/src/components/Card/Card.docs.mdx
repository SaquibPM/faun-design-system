## When to use

- To group content about one subject so it can be scanned as a unit on a page.
- As a large target that opens a detail page (`interactive`), or as an option in a visual choice (`selected`).

## When not to use

- For a row of KPIs: use StatGroup, which draws one surface with dividers.
- For a message about the page or system: use Banner.
- Inside another card: use spacing, a Divider or a muted section instead.

## Notes

- `asChild` renders your link or button as the card, so the whole surface is one target with native semantics. Don't put other interactive elements inside an interactive card.
- `padding="none"` lets media or tables run edge to edge; add padding to inner sections yourself.

## Screen readers

- CardHeader renders a real heading (level 3 by default). Set `level` so headings nest correctly on the page.
- A static card adds no role. If cards form a list, render them inside a `ul` with Stack `asChild`.

## Visual

- Card boundaries are drawn with a hairline border plus shadow, so they stay visible in high contrast and forced-colours modes.
- Selected adds a 2px brand border, not colour alone.
