## When to use

- **Stack** to space blocks vertically: sections of a card, fields in a form, cards in a column.
- **Inline** for horizontal runs that may wrap: button rows, tag lists, meta lines.
- **Divider** to separate groups that the spacing alone can't separate, or to label a break in a list ("Earlier this week").

## When not to use

- Two-dimensional layouts such as KPI rows or dashboards: use CSS grid, or StatGroup for KPIs.
- To separate every item in a list: use the list's own divided option (DescriptionList `divided`, Card footers) instead of a Divider per row.

## Anatomy

Stack and Inline are flex containers with no visual style of their own. Divider is a hairline in `border.subtle` (or `border.default` with `emphasis="default"`); a labelled divider centres caption text between two rules.

## Notes

- `asChild` renders your element instead of a div, so a Stack can be a `ul` or `section` without an extra wrapper.
- `gap` accepts space steps as strings (`"1.5"`, `"4"`) or `"density"`.
- `Separator` is an alias of `Divider`.

<Section tab="accessibility">

## Keyboard

Layout primitives are not focusable.

## Screen readers

- Stack and Inline add no semantics. Use `asChild` with a list element when the children are a list.
- Divider is decorative by default and hidden from assistive technology. Pass `decorative={false}` when the break is meaningful, which exposes `role="separator"` with its orientation.

## Visual

- Dividers are decorative and exempt from non-text contrast; don't use them as the only boundary of an interactive area.
