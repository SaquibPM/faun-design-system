## When to use

- For a bounded region of content that grows: run logs, evidence lists, long menus.
- When the platform scrollbar clashes with a themed surface.

## When not to use

- For the whole page. Let the page scroll.
- For tables with sticky headers and rows. Use the table component.
- Inside another scroll area. Nested scrolling traps keyboard and touch users.

Viewport, vertical and horizontal scrollbars with a thumb, and a corner. Scrollbars appear on hover or scroll and stay out of the content area.

## Notes

- Set `maxHeight` or size the root yourself, or nothing scrolls.
- `label` makes the viewport a focusable region so keyboard users can scroll it with the arrow keys.
- `type` follows Radix: `hover` (default), `scroll`, `auto` or `always`.

## Screen readers

- A labelled area is a named region. Unlabelled areas are not tab stops, so use them only around content that has focusable children.
