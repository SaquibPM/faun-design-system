## When to use

- To split one object into sections people move between freely: a report's overview, datapoints, gaps and history.
- To switch between views of the same data, such as table and chart, with the segmented variant.
- When every section is about the same thing and people rarely need two at once.

## When not to use

- For a sequence people must complete in order: use a Stepper.
- For navigation between different pages or objects: use the side navigation or Breadcrumbs.
- For a single setting with two or three values inside a form: use a Segmented control or Radio group.

## Content

- Use one or two words per tab, in sentence case. Nouns, not actions.
- Keep the order stable. Don't reorder tabs based on use.
- Disable a tab only when the reason is obvious from context; otherwise show it and explain inside the panel.

## Anatomy

A tab list and panels. Each tab has a label with an optional leading icon and count. The selected tab's label turns semibold, with width reserved so neighbours never shift.

## Variants

- **Line**: a 2px accent indicator on a hairline divider. The first tab aligns with the content edge.
- **Contained**: the selected tab joins a bordered panel on the surface colour.
- **Segmented**: a sunken track with a raised selected segment.

## Sizes

Medium tabs are 40px tall; small tabs are 32px for side panels and toolbars.

## Notes

- Built on Radix Tabs. Use `value` and `onValueChange` to control selection, for example to sync with the URL.
- Tabs activate on focus by default. Set `activationMode="manual"` when a panel is expensive to render.
- `TabsTrigger` takes `icon` and `count`; numeric counts are formatted with thousands separators.

## Screen readers

- The list has the `tablist` role and needs a name: pass `aria-label`, or `aria-labelledby` pointing at a visible heading.
- Each tab is linked to its panel, and panels are named by their tab.
- Counts are read as part of the tab name, so “Gaps 12” is announced. Make sure the number makes sense in that position.

## Visual

- The selected tab is marked by weight and the indicator, not by colour alone.
- In Windows high-contrast mode the indicator uses the system highlight colour.
