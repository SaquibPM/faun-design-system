## When to use

- For jargon and abbreviations inside body text, a table or a form label: tCO₂e, base year, market-based.
- When the definition is one or two plain sentences.

## When not to use

- For a definition that needs a link, a list or an action. Use a [Toggletip](/components/toggletip).
- To name an icon. Use [Tooltip](/components/tooltip).
- For a term every reader of the page already knows.

## Notes

- `definition` is plain content. For rich content use Toggletip.
- The term is a real `button`, so it is reachable by keyboard. It inherits the font of its surroundings.
- Hover opens after 200 ms. A press pins it; press again or press Escape to close.

## Keyboard

<Keys rows={[["Tab", "Focuses the term and shows the definition."], ["Enter or Space", "Pins the definition open, or closes it."], ["Escape", "Closes the definition."]]} />

## Screen readers

- The definition is attached with `aria-describedby`, so the term is read followed by its definition.

## Visual

- Meaning never depends on colour: the dotted underline marks a term. Focus draws the standard focus ring.
