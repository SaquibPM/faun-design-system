## When to use

- On every page that has repeated navigation before the content: side navigation, a header with links.
- It is already part of [App shell](/components/app-shell). Use `SkipLink` on its own for pages without the shell.

## When not to use

- Do not hide it permanently. It must appear on focus, otherwise sighted keyboard users cannot see where they are.
- Do not use it for in-page links to sections. Use [Link](/components/link) with an anchor.

## Writing

“Skip to main content” is the default. For a page with one obvious target, name it: “Skip to the filings table”.

## Notes

- `href` is the hash of the target. Give the target `tabIndex={-1}` so focus lands on it; the link also sets this if missing.
- AppShell uses the `skipLinkLabel` prop to change its text.

<Keys rows={[["Tab", "On a fresh page the first press focuses the skip link."], ["Enter", "Moves focus to the main content, skipping the navigation."]]} />

## Screen readers

- Announced as a link with its label. Screen reader users can also jump by landmark; the skip link serves keyboard-only users.

## Visual

- When focused it is fully visible with a 2px focus ring and 3:1 contrast against the page.
