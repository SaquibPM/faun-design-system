## When to use

- In table cells, tags, breadcrumbs, file names and ids where the width is fixed.
- When the full text still has to be reachable.

## When not to use

- For long prose people need to read. Use [Show more](/components/show-more) or let it wrap.
- For text that is essential to a decision. Never hide it behind a tooltip.

## Anatomy

A single-line block with an ellipsis. In middle mode, a shrinking head and a fixed tail of `tail` characters. The tooltip appears only while the text is cut, using the standard tooltip.

## Notes

- Children must be a string. The full text stays in the DOM in every mode.
- Truncation is measured with a resize observer, so the tooltip follows layout changes.

## Keyboard

<Keys rows={[["Tab", "Focuses text that is cut, so its tooltip can be read. Text that fits is not focusable."], ["Escape", "Closes the tooltip."]]} />

## Screen readers

- Screen readers read the full text once, whatever the visual cut. In middle mode the visual head and tail are hidden from assistive technology.

## Visual

- Focus shows the standard ring. Do not rely on the tooltip for essential information.
