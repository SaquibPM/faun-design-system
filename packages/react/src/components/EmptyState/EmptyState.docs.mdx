## When to use

- A list, table, panel or page that has no content: because nothing has been created, a filter matched nothing, loading failed, or the person can't see it.

## When not to use

- While content is loading: use Skeleton.
- For a problem affecting a page that still has content: use Banner.

## Writing

Title says what's missing in plain words (“No filings yet”). Description says why or what it's for, in one sentence. The primary action is a verb plus object (“New filing”). For errors, say what failed and offer retry; never blame the person.

## Notes

- Pass `icon` to replace the default visual with a domain icon.
- `level` sets the heading level (default 2). Use 3 inside a card that has its own heading.
- Actions are your own Buttons, so they can be links or open dialogs.

## Screen readers

- The title is a real heading, so the empty state is discoverable by heading navigation.
- The visual is decorative and hidden. If the state replaces content after a filter changes, announce the result count in a live region.

## Visual

- Text meets 4.5:1 on the surface; the visual conveys nothing the text doesn't.
