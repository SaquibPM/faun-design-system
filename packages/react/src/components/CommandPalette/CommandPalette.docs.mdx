## When to use

- To give power users one place to reach any page, agent, run or action by typing.
- Alongside visible navigation, never instead of it.

## When not to use

- To pick a value for a form field. Use [Combobox](/components/combobox).
- To page through results with filters. Build a search page.

## Writing

- Group commands as “Navigate”, “Actions” and “Recent runs”.
- Add `keywords` for synonyms people will type (“disclosure” for a filing).
- Empty message says what to try next.

## Anatomy

A raised panel near the top of the screen over a scrim: a search row with an Esc hint, a scrolling grouped list, and a footer with key hints. Options reuse the list option row used by Select and Combobox.

## States

Rows highlight with the hover background as you arrow through them. Disabled rows are dimmed and skipped.

## Notes

- The palette is controlled with `open` and `onOpenChange`. With `hotkey` (default) ⌘K and Ctrl+K toggle it from anywhere.
- `shortcut` on an item is a display hint. Bind the key in your app.
- Set `filter={false}` and use `onSearchChange` to search on the server.

## Screen readers

- Announced as a dialog with the name “Command palette”. The input is a combobox controlling the list, and the active row is announced as you arrow.

## Visual

- Focus stays in the search field. The highlighted row uses a background change plus the focus ring in forced-colours mode.
