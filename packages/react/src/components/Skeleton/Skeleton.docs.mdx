## When to use

- When a page, card or table is loading and you know roughly what it will look like.
- For waits of more than about 300ms. Shorter loads can render nothing and avoid a flash.

## When not to use

- For a short action on a button: use the button's loading state.
- For long-running agent work with measurable progress: use Progress.
- For content that has loaded and is empty: use EmptyState.

## Notes

- Skeleton is `aria-hidden`. Put `aria-busy="true"` on the region that is loading and announce completion with a live region if it matters.
- `SkeletonRows` is a `role="status"` with a label, so one message is announced for the whole table.

<Section tab="accessibility">

## Keyboard

Not focusable.

## Screen readers

- Individual skeleton shapes are hidden. Mark the loading region with `aria-busy="true"`; SkeletonRows announces its `label` (default “Loading”) as a status.
- Replace the skeleton with real content in the same place so focus and reading position stay stable.

## Visual

- Placeholders are decorative; no contrast requirement applies. Motion is removed for reduced-motion users.
