## When to use

- To offer several actions on one object without crowding the screen: the actions for an agent, a run or a table row.
- To switch a view setting, such as visible columns or sort order, from a compact control.

## When not to use

- For the primary action: put it on the page as a button. Menus hide actions.
- For choosing a value in a form: use a Select or Combobox, which show the current value.
- To search across the product: use the Command palette.
- For free-form content or a form: use a Popover.

## Writing items

- Start with a verb in sentence case: “Archive”, “Use in workflow”, “Export run history”.
- Order by frequency, then group with separators. Put destructive items last, after a separator, in the danger intent.
- Keep menus under about ten items. If a menu grows longer, split it or move items to a dedicated page.

## Anatomy

Each item has an optional leading icon, a label, an optional description line and an optional shortcut hint. Checkbox and radio items reserve an indicator column. The panel sits on elevation 3 with a subtle border and 4px of inner padding; items have a 6px radius and highlight with the neutral hover tint.

## Notes

- Use `onSelect` on items for actions. For links, pass `asChild` and render an anchor.
- Checkbox items call `preventDefault` on select so the menu stays open; radio items close it.
- Shortcuts are display only. Register the key handler yourself, and keep the hint in sync.
- `DropdownMenuContent` accepts `matchTriggerWidth` for menus attached to wide triggers.

## Screen readers

- The panel has the `menu` role; items are `menuitem`, `menuitemcheckbox` or `menuitemradio` with their checked state.
- Typing a letter moves to the next item starting with it.
- Icons and shortcut hints are hidden from assistive technology so the label is read cleanly. Icon-button triggers must name the object, for example “Actions for CSRD Discovery”.

## Visual

- Destructive items use the danger text colour, which meets 4.5:1 on the menu surface and on the hover tint in every theme.
- Items are at least 32px tall, above the 24px target minimum.
