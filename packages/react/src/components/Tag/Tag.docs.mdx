## When to use

- To name the framework, topic or entity something belongs to: CSRD, ESRS E1-6, Climate.
- To show filters that are already applied, with a way to remove them.
- Use `FilterChip` for quick filters people switch on and off.

## When not to use

- For status of a run, filing or data point. Use [Badge](/components/badge) with a status.
- For a counter. Use a solid Badge.

## Anatomy

Optional icon, label and optional remove button. Interactive tags (selectable, operational) put the icon and label inside a button; the remove button stays separate. Tags are fully rounded. Framework tags use the mono face.

## Notes

- Pass a string child so the default remove label can say what is removed, or set `removeLabel`.
- `selectable` with `selected` and `onSelectedChange` makes a toggle; `variant="operational"` or `selectable` puts `onClick` and other props on the inner button. `disabled` greys the tag out and removes it from the tab order.
- `TagGroup` takes `max`, `label` and `moreLabel`; keep the visible “+N” in the label.
- `FilterChip` takes `selected` and `onSelectedChange`, and an optional `count`.

## Screen readers

- Selectable tags and chips are announced as toggle buttons with a pressed state. Operational tags are plain buttons. The +N tag is named “+3 more”.
- Filter chips are announced as toggle buttons with a pressed state. Remove buttons are named “Remove” followed by the tag text.

## Visual

- Text meets 4.5:1. The remove button keeps the minimum target size around the icon.
