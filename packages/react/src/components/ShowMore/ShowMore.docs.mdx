## When to use

- For long supporting text in a card or panel: narratives, notes, lists of sources.
- When most people need only the first lines.

## When not to use

- For single-line labels. Use [Truncate](/components/truncate).
- For several sections with their own headings. Use an [Accordion](/components/accordion).
- For anything people must read before acting.

## Notes

- Controlled use: `expanded` and `onExpandedChange`. Start open with `defaultExpanded`.
- The full content is in the page even when collapsed, so search and assistive technology can reach it.

## Screen readers

- The toggle sets `aria-expanded` and `aria-controls` for the content, and its text changes between the more and less labels.

## Visual

- The toggle uses the link colour, meeting 4.5:1, and shows the standard focus ring.
