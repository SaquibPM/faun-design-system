## When to use

- For a short wait, up to a few seconds, where the length is unknown: loading a list, saving a form.
- Inside a button that is running an action (Button has a `loading` prop).

## When not to use

- When you know how far along the work is. Use [Progress](/components/progress).
- For page or table layouts that load in. Use [Skeleton](/components/skeleton).
- For agent runs that take minutes. Start the run and show its state with a status badge and a progress indicator.

## Anatomy

A circular track with a rotating arc. The spinner draws in the current text colour, so it matches the context it sits in.

## Notes

- `label` defaults to “Loading”. Pass a specific label such as “Drafting ESRS E1-6”, or `label={null}` when a parent already announces the busy state.

<Section tab="accessibility">

## Keyboard

Spinners are not interactive.

## Screen readers

- A spinner is a status with the accessible name from `label`. With `label={null}` it is hidden and the parent must announce progress (a Button sets `aria-busy`).

## Visual

- The arc meets 3:1 against its background. Never rely on the spinner alone: pair it with text when the wait is more than a moment.
