## When to use

- For settings that take effect as soon as they change: notify reviewers, show estimated values.
- For a feature flag or preference in a settings list.

## When not to use

- For a choice that needs a Save or Submit. Use [Checkbox](/components/checkbox).
- For picking among options. Use [Radio group](/components/radio-group).

## Writing

Label the setting, not the state: “Notify reviewers”, not “Notifications are on”. Keep the label the same whether on or off.

## Read-only and loading

<Example of="Switch/StateContract" title="Read-only and loading" description="Read-only shows the setting's current value but ignores changes, and sets aria-readonly.
