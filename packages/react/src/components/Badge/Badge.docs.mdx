## When to use

- To show the state of a run, filing, task or data point beside its name.
- To mark a count on a navigation item or a short category such as “New”.

## When not to use

- For frameworks or topics people can add and remove. Use [Tag](/components/tag).
- For a clickable filter. Use a filter chip from Tag.
- For a message that needs reading. Use a Banner.

## Status

Use `StatusBadge` with a domain and state from the status map. It chooses the tone, icon and label, so a state looks the same everywhere. **Running** (lagoon) is a machine working now. **Needs you** (plum) is waiting on a person: do not swap them for info or warning.

## Notes

- `StatusBadge` accepts `domain` and `state`, or `tone` and `label` for your own states.
- Unknown states fall back to a neutral badge with the state as its label.

<Section tab="accessibility">

## Keyboard

Badges are not interactive.

## Screen readers

- The label is real text, so status is read aloud. Icons and dots are decorative.

## Visual

- Label text meets 4.5:1 on every tone in every theme. Status never relies on colour alone.
