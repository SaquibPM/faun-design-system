## When to use

- To select any number of independent options: scopes to include, sites to report.
- For a single agreement or setting that is applied on Save.
- For selecting rows in a table, including a select-all with the mixed state.

## When not to use

- For exactly one choice from a list. Use [Radio group](/components/radio-group).
- For a setting that takes effect immediately. Use [Switch](/components/switch).

## Writing

Label each box with the thing being chosen, not the action: “Scope 2”, not “Include Scope 2”. Put the answer in the label so it reads as true when checked.

## Warn, read-only and loading

<Example of="Checkbox/StateContract" title="Warn, read-only and skeleton" description="Warn marks a value that is allowed but worth a second look. It is never the same as invalid: it does not set aria-invalid and never blocks submission, and the message carries an icon and text so it is not colour alone. Read-only shows the value flat, keeps it focusable and copyable, and ignores changes. Skeleton replaces the control while its data loads; the label stays for screen readers. Set all three on a Field and every control inside follows." />

Set `warn` (a message), `readOnly` and `skeleton` on the surrounding `Field`. On a standalone checkbox group, pass `readOnly` and `skeleton` directly; give `warn` a message through a Field so it is announced. An error always replaces a warning.

## Notes

- `CheckboxGroup` takes `options`, `value` (string array) and `onValueChange`. A single `Checkbox` takes `checked` and `onCheckedChange`, with `"indeterminate"` as a third state.
- Inside a table row, omit the label and pass an `aria-label` that names the row.

## Screen readers

- Announced as a checkbox with its checked, unchecked or mixed state. Groups are announced with their label.
- Descriptions and errors are linked to the box.

## Visual

- The box border meets 3:1 against the surface. The target includes the label, so the whole row is clickable.
- A check mark or dash shows state, so it never relies on colour alone.
