## When to use

- To show supporting detail on demand: the source of a factor, the calculation behind a figure, the definition of an ESRS datapoint.
- For a quick setting or a short form of one or two fields that applies to what's on screen.
- As the container for filters, pickers and custom menus.

## When not to use

- For a short, non-interactive hint on hover: use a Tooltip.
- For a list of actions: use a Menu, which brings arrow-key navigation and typeahead.
- For tasks that need focus, several fields or a confirmation: use a Dialog or a Sheet.
- For a preview of a linked object on hover: use a Hover card.

## Anatomy

A popover is a raised surface with an optional header (title and description), a body, an optional footer of actions, an optional close button and an optional caret (`arrow`). It sits on elevation 3 with a subtle border, so it reads in every theme including high contrast.

## Controlled

Pass `open` and `onOpenChange` to `Popover` to control it, for example to close it after an async save. `PopoverClose` closes the popover from any element inside it.

<Example of="Popover/WithForm" title="Form with close actions" code="open" height={340} />

## Notes

- `PopoverContent` portals to the body and flips to stay inside the viewport (`collisionPadding` 8px).
- Use `flush` to drop the padding when the content manages its own layout, such as a list or calendar.
- `align` defaults to `start`; `side` defaults to `bottom`. `arrowPadding` keeps the caret 16px from the corner.
- `tone="inverse"` switches to the inverse surface; `arrow` draws a bordered caret.

## Screen readers

- The trigger announces its expanded state with `aria-expanded` and points to the panel with `aria-controls`.
- The panel has the `dialog` role. Give it a name with a `PopoverHeader` title or `aria-label` on `PopoverContent`.
- Focus moves into the popover when it opens and returns to the trigger when it closes.

## Visual

- The surface uses a 1px border as well as a shadow, so its edge stays visible in high-contrast themes, where shadows are removed.
- Text inside follows the normal contrast contract: 4.5:1 for muted text, 7:1 for body text.
