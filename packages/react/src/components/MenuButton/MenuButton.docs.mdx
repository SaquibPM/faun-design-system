## When to use

- Menu button: when one label stands for several related actions or formats (Export, Add filter, New).
- Combo button: when one action is the usual choice and a few close variants exist (Run now, with Run with sample data).

## When not to use

- For a single action. Use a [Button](/components/button).
- For per-row actions with no label. Use an [Overflow menu](/components/overflow-menu).
- For choosing a value that stays selected. Use a [Select](/components/select).

## Notes

- Pass menu content with `menu`. Everything else on MenuButton is a Button prop; `onClick` belongs to ComboButton's primary action only.
- Set `menuLabel` on ComboButton to name the chevron for this action: “Run options”.

## Screen readers

- Menu buttons announce as menu buttons (`aria-haspopup="menu"`) with their expanded state.
- A combo button is a labelled group of two buttons.

## Visual

- Both halves of a combo button are separate targets of at least the button height.
