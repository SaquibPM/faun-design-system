## When to use

- Dialog, sheet and card footers with a primary and one or two other actions.
- A set of closely related buttons that read as one control (joined).

## When not to use

- For more than three actions. Move the extras into a [Menu button](/components/menu-button) or [Overflow menu](/components/overflow-menu).
- For choosing one option that stays selected. Use a [Segmented control](/components/segmented-control).

## Notes

- Order from quiet to loud: tertiary, secondary, primary last. Below 480px with `stack="narrow"` the order reverses so the primary is on top.
- Pass `aria-label` when the buttons need shared context.

## Screen readers

- The group has `role="group"`. Give it a name when the buttons are ambiguous alone.

## Visual

- In joined groups the hovered or focused button rises above its neighbours so its focus ring is never clipped.
