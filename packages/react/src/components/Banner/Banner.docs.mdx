## When to use

- To tell people about a condition that affects the content around it and stays true until something changes: a failed import, an approaching deadline, work waiting on them.
- At the top of a page (`variant="page"`) for conditions that affect the whole page or workspace.

## When not to use

- For the result of an action the person just took: use a Toast.
- For the status of one item in a list or table: use a Badge.
- For a page with nothing to show: use EmptyState.

## Writing

Titles are one short sentence stating the condition. Text adds the detail or the next step. Put the action (Review, Fix file) in `actions` rather than in prose.

## Anatomy

Tone icon, title, optional text, optional timestamp, optional action, optional actions slot, optional dismiss button. A visually hidden tone word (“Error”, “Warning”) precedes the title for screen readers. Icons come from the status map so each tone is recognisable without colour.

## Notes

- `role` is chosen from the tone (`alert` for danger and warning, `status` otherwise). Override with the `role` prop when a banner appears on page load and should not interrupt.
- `contrast` is `low` or `high`. `actionLabel` with `onAction` is the single action of an actionable notification; `actions` is still there for several.
- Pass `icon={null}` to hide the icon or any node to replace it.

## Screen readers

- Danger and warning banners use `role="alert"` and are announced when they appear; other tones use `role="status"`.
- The dismiss button is named “Dismiss”. When dismissing, move focus somewhere sensible, such as the next control.

## Visual

- Text meets 4.5:1 on the tone background in every theme. High contrast uses the solid tone with its on-solid text, which meets 4.5:1. The tone is carried by icon and wording as well as colour.
