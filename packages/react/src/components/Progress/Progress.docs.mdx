## When to use

- **ProgressBar** for work that moves toward completion (a run, an import, drafting) or for coverage of a total (812 of 1,034 datapoints).
- **ProgressCircle** where space is tight: table cells, cards, step indicators.
- **Meter** for a measurement that is not a task: evidence coverage, data quality, intensity against a target. It changes colour at thresholds.

## When not to use

- For an unknown wait with no measurable progress on a small control: use Spinner. For page and section loads: use Skeleton.
- For a single number without a range: use Stat.

## Notes

- ProgressBar is built on Radix Progress; segmented mode renders one `role="progressbar"` with `aria-valuetext`.
- `status` is `active` (default), `finished` or `error`. Finished sets the value to the maximum. `statusText` replaces the default “Finished” and “Failed” and is also in `aria-valuetext`; on an error write the cause and the fix.
- Announcements: see Accessibility. Pass `announce={false}` for bars in a table or list, where many announcements would talk over each other.
- Always give a `label` or `aria-label`. `ProgressCircle` requires `aria-label`.
- Meter uses `role="meter"`, which is the right role for a gauge that is not a task.

<Section tab="accessibility">

## Keyboard

Progress indicators are not interactive and not focusable.

## Screen readers

- Named `progressbar` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`; indeterminate bars omit `aria-valuenow`.
- Segmented bars announce their composition in `aria-valuetext`.
- Announcement contract, built in and active after mount only: becoming indeterminate says “Label: in progress”; a determinate bar says “Label: 50%” each time it crosses 25, 50 or 75 percent upward (not every tick); finished says “Label: finished” politely; error says “Label: failed” plus the status text as an alert. A bar that is first rendered at any value says nothing. Set `announce={false}` to silence a bar.
- `finished` and `error` carry `aria-valuetext` (“Finished”, “Error: …”) and visible text with an icon.

## Visual

- Fills meet 3:1 against the track in every theme. Meter colours are never the only signal: the value is always shown or announced.
- Indeterminate motion stops under reduced motion.
