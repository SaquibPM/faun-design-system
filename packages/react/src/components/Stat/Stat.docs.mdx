## When to use

- To lead a page or card with the number that matters: emissions, coverage, open approvals.
- In a KPI row, so people compare figures at a glance.

## When not to use

- For many numbers that need comparing across rows. Use a table.
- For trends over time. Use a chart, and a Stat only for the latest value.

## Writing

Format numbers before passing them in: thousands separators, sensible decimals, units as a separate prop (“tCO₂e”, “%”). Say what a change compares to: “vs base year 2022”.

## Notes

- Figures use tabular numerals so values line up across stats.
- `delta.direction` draws the arrow. `delta.sentiment` (good, bad, neutral) sets the colour.
- `variant="plain"` on StatGroup removes the shared surface.

<Section tab="accessibility">

## Keyboard

Stats are not interactive.

## Screen readers

- The change is spoken as words, for example “down 4.2% vs base year 2022”. The arrow and visible duplicate are hidden from assistive technology.

## Visual

- Colour never carries the change alone: the arrow gives direction, the text gives size. Sentiment colours meet 4.5:1.
