## When to use

- For familiar, repeated actions in toolbars, table rows and card corners: edit, copy, download, more.
- Where a text button would crowd the layout.

## When not to use

- For the primary action in a view. Use a [Button](/components/button) with a text label.
- For an icon people might not recognise. Add text, or use a Button with a leading icon.

## Notes

- `label` is required. Set `tooltip={false}` when a visible label or another tooltip already names the control (for example inside a Popover close).
- It accepts every Button prop except icons, children and `asChild`.
