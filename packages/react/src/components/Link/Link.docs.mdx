## When to use

- To navigate to another page, a document, a run log or an external standard.
- Inside sentences, captions and table cells where a button would be too heavy.

## When not to use

- To trigger an action such as approve, export or delete. Use [Button](/components/button).
- For a trail of parent pages. Use [Breadcrumbs](/components/breadcrumbs).

<Section tab="style">

## Anatomy

Link text in the link colour, an underline, and an optional external icon after the text. Links inherit the font size and weight of the text around them.

## States

Default, hover (darker colour, underline), focus (focus ring), disabled (`aria-disabled`).

## Notes

- Use `asChild` to render your router's link, so navigation stays client side.
- `external` sets `target="_blank"` and `rel="noopener noreferrer"`. Set it only for other sites.

## Screen readers

- External links add the hidden text “(opens in a new tab)” to the accessible name.

## Visual

- Link text meets 4.5:1 against every surface. Underlines mean links are not identified by colour alone.
