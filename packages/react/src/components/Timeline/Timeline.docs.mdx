## When to use

- To show who did what and when on a filing, run or evidence item.
- To let auditors trace a figure back through approvals and agent steps.

## When not to use

- For the steps of a process the person moves through. Use [Stepper](/components/stepper).
- For notifications. Use Banner or Toast.

## Writing

Agents show with the agent mark and name the agent, so people never mistake machine work for a person's. Use a time label people can read (“20 Oct, 09:12”) and an ISO time for machines.

## Anatomy

An ordered list. Each entry has an avatar marker joined by a line, an actor name with the action, a time, an optional status badge and an optional details panel.

## Notes

- Items are `{ id, actor, action, time, timeLabel?, status?, details?, defaultOpen? }`. `status` uses a domain and state from the status map.
- Give the list an `aria-label` that names what it is the trail of.

## Screen readers

- An ordered list of entries. Times use the `time` element with a machine-readable value. Avatars are decorative because the name is in the text.

## Visual

- Status always shows an icon and a word. Details toggles show a rotating chevron and their expanded state.
