## When to use

- To name an icon-only control. [Icon button](/components/icon-button) does this for you.
- To add a short note about a control, such as why it can't be used right now.

## When not to use

- For essential information, instructions or errors. Put them on the page.
- For interactive content or long text. Use [Popover](/components/popover) or [Hover card](/components/hover-card).
- On touch-only screens as the only route to information. Touch devices have no hover.

## Anatomy

A small inverse-coloured bubble with text and an optional shortcut. It appears after a delay of 400ms and opens instantly for a moment after another closes.

## Notes

- The trigger must be focusable. Wrap a disabled button in a span or use `aria-disabled` so the tooltip can still open.
- `TooltipProvider` sets delays for the whole app. Tooltip also works without it.
- Pass `disabled` to skip the tooltip when the label is already visible.

## Screen readers

- The tooltip is linked to its trigger as a description. Because it may be missed, never put the only name or instruction there, except for icon-only controls, which also carry an `aria-label`.

## Visual

- Text meets 4.5:1 on the inverse surface. The tooltip stays open while the pointer is over it.
