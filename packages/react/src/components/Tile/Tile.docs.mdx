## When to use

- To choose between a few options that need a title and a line of explanation: a framework, a method, a plan. Use selectable tiles.
- To send people somewhere from a grid of destinations. Use clickable tiles.
- To show a short summary with detail that opens in place. Use an expandable tile.

## When not to use

- For a long list of options or short labels. Use a [Radio group](/components/radio-group), [Checkbox](/components/checkbox) or [Select](/components/select).
- For a block with a header, actions and a footer. Use a [Card](/components/card).
- For several panels of long content. Use an [Accordion](/components/accordion).

## Writing

A title in sentence case, then at most one line of detail. For clickable tiles the title is a verb phrase. For selectable tiles it is the thing chosen (“CSRD”, “Market-based”). Keep to text and inline elements inside a tile: a tile is a single control.

## Anatomy

A hairline-bordered surface with a body (title and detail). Clickable tiles end with an arrow. Selectable tiles end with an indicator: a square with a check for several, a circle with a dot for one. Expandable tiles end with a chevron that turns when open.

## States

Hover raises the border and tints the surface. Selected uses the brand border and a soft brand fill with a filled indicator. Disabled uses the disabled surface, border and text. Focus draws the focus ring around the whole tile.

## Notes

- `TileGroup` renders a fieldset with a required `legend`. `type` is `radio` (default; `value`, `onValueChange`) or `checkbox` (`values`, `onValuesChange`). `disabled` and `readOnly` apply to every tile; `minTileWidth` sets the grid.
- `SelectableTile` is a native input under the tile, so forms, `name`, `required` and autofill hints work. Give each tile in a group a `value`.
- `ClickableTile` renders `a` with `href` and `button` without. A disabled link loses its `href` and stays in the tab order as a disabled link; a disabled button leaves it.
- `ExpandableTile` takes `summary`, `open`, `defaultOpen` and `onOpenChange`. Closed content is hidden from assistive technology.

## Screen readers

- Clickable tiles are a link or a button named by their text. Selectable tiles are checkboxes or radios named by their text, in a fieldset named by the legend, with the description read after it.
- Expandable tiles are a button with `aria-expanded` and `aria-controls`; the detail is a region named by the button. Collapsed detail is not read.
- Read-only tiles keep their state and set `aria-readonly`.

## Visual

- Selection is shown by a filled check or dot and a border, not colour alone. In forced-colours mode the selected tile gets a system highlight outline.
- The focus ring surrounds the whole tile, including when the hidden input has focus.
