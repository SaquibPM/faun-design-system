## When to use

- To switch how the same content is shown: Gross or net, Table or chart.
- For two to four short options that apply immediately.

## When not to use

- To move between sections of a page. Use [Tabs](/components/tabs).
- For more than about four options. Use [Select](/components/select).
- For choices submitted with a form. Use [Radio group](/components/radio-group).

Labels are one or two words in sentence case. Options must be parallel.

## Notes

- `options` are `{ value, label, icon?, disabled?, aria-label? }`. Icon-only options need an `aria-label`.
- The control needs an accessible name from `aria-label` or `aria-labelledby`.

## Keyboard

<Keys rows={[["Tab", "Moves focus to the selected option."], ["← / → / ↑ / ↓", "Moves to and selects the previous or next option."], ["Home / End", "Moves to the first or last option."]]} />

## Screen readers

- Announced as a radio group with a name. Each option is a radio with a checked state, and arrow keys move the selection.

## Visual

- The selected option has a raised thumb, a stronger text colour and a border, so selection survives forced colours.
