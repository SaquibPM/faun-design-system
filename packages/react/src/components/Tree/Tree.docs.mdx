## When to use

- To pick a node in a real hierarchy: entities, facilities, topics, folders.
- When people need to see the whole structure and move around it quickly.

## When not to use

- For a flat list. Use [Select](/components/select) or a list.
- For revealing content sections one at a time. Use [Accordion](/components/accordion).
- For site navigation. Use the AppShell side navigation.

<Section tab="style">

## Anatomy

A list of rows, each with an expand chevron, optional icon, label and trailing meta. Children are indented one step per level, with subtle guides. The selected row has the selected background.

## States

Default, hover, selected, focus (ring on the row), disabled.

## Notes

- Nodes are `{ id, label, icon?, meta?, children?, disabled?, textValue? }`. Give `textValue` when the label is not a string so type-ahead works.

- Announced as a tree. Each item exposes its level, position in its set and expanded state.

- Selection uses a background plus a text change, and the focus ring is shown on the row.
